# Douaa & Rachid Wedding Invitation

## Objectif

Créer une invitation de mariage électronique haut de gamme en React, inspirée du luxe méditerranéen.

Le fichier `design/brand-book.html` est la référence artistique officielle.

Ne jamais inventer un nouveau design sans s'appuyer sur ce Brand Book.

---

## Technologies

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- GSAP

---

## Design

Style :

- Mediterranean Quiet Luxury
- Minimaliste
- Élégant
- Raffiné
- Inspiré de La Perle du Lac

Palette :

- Ivoire
- Champagne
- Bronze
- Bleu Méditerranée
- Olive

Typographies :

- Playfair Display
- Cormorant Garamond
- Inter

---

## Animations

Le site doit raconter un voyage.

Ordre :

1. Paris
2. Avion
3. Méditerranée
4. La Perle du Lac
5. Enveloppe
6. Invitation
7. Cartes

Les animations doivent être fluides.

---

## Composants

Créer des composants indépendants.

Ne jamais écrire toute l'application dans App.tsx.

Créer notamment :

- Opening
- FlightAnimation
- Envelope
- InvitationCard
- Timeline
- Program
- Tribute
- Venue
- GiftRegistry
- RSVP
- Gallery

---

## Développement

Toujours procéder étape par étape.

Avant toute modification :

1. Lire `design/brand-book.html`
2. Respecter la direction artistique
3. Expliquer le plan
4. Développer uniquement la fonctionnalité demandée

---

## Langues

Le site est bilingue :

- Français
- Arabe

Utiliser le RTL uniquement pour l'arabe.

---

## Qualité

Le code doit être :

- propre
- modulaire
- réutilisable
- responsive
- accessible
- performant
